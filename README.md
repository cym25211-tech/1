# 信号探险岛 · 模拟电子技术

依据所附《模拟电子技术基础》2.1—2.7 学习笔记，沿着“放大与性能指标—三极管工作点与波形—分析模型与反馈—场效应管和复合管”展开。

成品文件：[index.html](./index.html)。全景配图、字体、60 个分阶段图解和交互脚本均已内嵌，核心课程可离线使用。

图文阅读版：[信号探险岛学习笔记.pdf](./信号探险岛学习笔记.pdf)。61 页，包含全部章节讲解、20 幅关键图解、60 条拓展、80 个术语和练习答案，可在苹果手机“文件”中直接阅读。

包含 20 个主题、60 条详细拓展、80 个术语解释、60 道概念题，以及可以调节参数、比较条件的实验。每章都有生活故事、形象比喻、公式条件、常见误解和可以继续探究的问题。

实验覆盖增益与分贝、输入输出加载、频响与噪声、削顶、BJT 工作区、静态工作点、负载线、共射反相、直流交流通路、混合 π 模型、分压偏置反馈、共射/共基/共集比较、MOS 工作区和自洽工作点、三种场效应管接法与达林顿接力。实验采用明确标注适用域和简化条件的教学模型。

图解可放大查看，手机可左右滑动看器件与波形细节。削顶实验可以点击试听当前波形约一秒，比较音色；声音只有点击后才播放。探究记录支持本机保存和 TXT 导出，知识笔记支持打印，概念题支持错题回顾。

下载完整文件：[下载 ZIP](https://github.com/cym25211-tech/1/archive/refs/heads/signal-island.zip)。

- 电脑：解压后使用 Chrome、Edge 或 Safari 打开 `index.html`。
- 苹果手机：将下载链接复制到 Safari 下载，再到“文件”中点击 ZIP 解压。PDF 笔记可以直接打开阅读；`index.html` 的离线交互需要支持 JavaScript 的 HTML 查看器，Safari 直接运行需要将 HTML 发布为网站。

探究记录保存在当前浏览器或查看器中，建议及时导出文本备份。清理浏览器数据或更换查看器可能使原记录不可见。
