# 金属资源探究岛

以“金属资源的利用和保护”课本内容为基础，从矿石、炼铁、锈蚀一路探索到循环利用和稀土材料。

成品文件：[index.html](./index.html)。全景配图、字体、48 个分阶段图解和交互脚本均已内嵌，核心课程可离线使用。

包含 16 个主题、48 条扩展知识、64 个术语解释、48 道概念题，以及可改变条件的探究实验。学习时可以先写预测，再改变条件，收集实验结果，用证据解释，继续提出问题。探究记录支持本机保存、文本导出，知识笔记支持打印。

实验包括矿石分类与磁选、冶炼路线选择、高炉配料、含杂质计算、限制原料与回收率、铁锈对照、涂层破损、金属钝化、资源回收预算和重复观察数据分析。虚拟实验中的假设、适用条件与现实限制均在页面中说明。

下载完整文件：[下载 ZIP](https://github.com/cym25211-tech/1/archive/refs/heads/metals-island.zip)。

- 电脑：解压后使用 Chrome、Edge 或 Safari 打开 `index.html`。
- 苹果手机：在 Safari 中打开上面的下载链接，下载后到“文件”中点击 ZIP 解压，找到 `index.html`。离线运行交互课程需要支持 JavaScript 的 HTML 查看器；Safari 直接运行需要将 HTML 发布为网站。

探究记录保存在当前浏览器或查看器中，建议及时导出文本备份。清理浏览器数据或更换查看器可能使原记录不可见。
