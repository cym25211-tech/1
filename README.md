# 能源探险岛 · 精细互动版

成品文件：[index.html](./index.html)。图片、字体、样式和交互脚本均已内嵌。

包含能源岛全景、12 关的分阶段动态图解和实验、生活故事、术语词典、课内与拓展问答、错题回顾、打印笔记。

电脑：下载 `index.html`，使用 Chrome、Edge 或 Safari 打开。

苹果手机：先取得实际文件。离线运行需要支持 JavaScript 的 HTML 查看器；通过 Safari 使用时，需要将 `index.html` 部署到静态网站。

下载完整文件：[下载 ZIP](https://github.com/cym25211-tech/1/archive/refs/heads/energy-island.zip)。苹果手机可在 Safari 中下载，再到“文件”中点击 ZIP 解压，成品文件名为 `index.html`。

若仓库需要登录，请先使用拥有该仓库访问权限的 GitHub 账户登录。
